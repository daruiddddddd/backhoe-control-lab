# バックホー操作練習室

主観視点でバックホーの操作を試す、非公式のブラウザゲームです。PC・iPhone・iPad・Android向け。ログイン不要。

## 遊び方

最初に縦旋回（オレンジ）または横旋回（ブルー）を選びます。左右のレバーを指・マウスで動かすか、WASDと矢印キーで操作できます。

入力方法は自動切り替えです。指・ペンで触れたら指操作、キーボード・マウスを使ったらPC操作になります。「詳しく」の入力方法で固定もできます。画面の操作表示は隠す／戻すを切り替えできます。

土にバケットを当て、アームとバケットをかき込むと穴が掘れます。持ち上げて旋回し、ダンプすると土が積もります。

右下「秘密の変形」でヘリコプターまたは戦闘機へ。飛行中は左レバーで前後移動・旋回、右レバーで昇降・横移動。「バックホーへ戻る」で元の位置へ自動帰還してから機体を復元します。

## iPhone・iPadでオフライン利用

1. 公開ページをSafariで開きます。
2. 「オフラインの準備ができました」を確認します。
3. 共有メニューから「ホーム画面に追加」を選び、ホーム画面から起動します。

初回の保存には通信が必要です。端末がサイトデータを削除した場合は、もう一度通信ありで開いてください。スマホは横向き推奨。PCでは [offline.html](offline.html) を保存してブラウザで開けば、最初から通信不要です。

## 操作表

|左レバー / キー|縦旋回 C|横旋回 ISO|
|---|---|---|
|前 / W|右旋回|アーム伸ばし|
|手前 / S|左旋回|アームかき込み|
|左 / A|アーム伸ばし|左旋回|
|右 / D|アームかき込み|右旋回|

右レバーは両方式共通です。前（↑）はブーム下げ、手前（↓）はブーム上げ、左（←）はバケットかき込み、右（→）はダンプ。

操作は[クボタRX-506の公式操作表](https://kubotakenki.co.jp/manual/pdf/rx-series/rx-506/manual/rx-506_manual03.pdf)のPDF6〜7ページを参照。内装は[公式カタログ](https://www.kubota.co.jp/product/machinery/support/pdf/RX-506.pdf)を参考にしています。寸法、油圧、土の物理、飛行は簡易モデルです。実機ではその機体の操作表示を確認してください。
